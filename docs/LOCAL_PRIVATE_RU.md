# Личные данные и репозиторий

Harness настраивается под конкретную машину: облако для ссылок, аккаунты,
пути к проектам. Всё это должно оставаться на ПК. Репозиторий содержит только
общие механизмы; личное подключается через переменные окружения и папки вне Git.

## Где что лежит

| Что | Где | В Git |
|---|---|---|
| Код harness, общие скрипты, документация | репозиторий | да |
| Токены агента и моста | `%USERPROFILE%\.chatgpt-desktop-agent\` | нет |
| Идентичность Remote Commander | `%USERPROFILE%\.desktop-commander-device\` | нет |
| Загрузчик для ссылок (ваше облако/сервер) | `%USERPROFILE%\.rdc-workstation-harness\local\` (или `local\` в клоне) | нет |
| OAuth облака (rclone и т. п.) | `%APPDATA%\rclone\rclone.conf` | нет |
| Выбор загрузчика | переменная `RDC_HARNESS_SHARE_CMD` | нет |
| Личные стоп-слова | `local\denylist.txt` | нет |

Harness узнаёт о вашем загрузчике только через `RDC_HARNESS_SHARE_CMD`. Имени
облака, аккаунта или ссылки в коде нет, и добавлять их туда не нужно.

## Защита от случайного коммита

Три слоя, от самого раннего:

1. **`.gitignore`** — `local/*`, `*.local.*`, `rclone.conf`, `share-*.ps1`,
   токены, профили браузера. Такие файлы просто не попадают в `git add`.
2. **pre-commit хук** (`.githooks/pre-commit`) — включается один раз на клон:

   ```powershell
   git config core.hooksPath .githooks
   ```

   Он блокирует коммит, если:
   - в индекс попал файл из `local/` (кроме README);
   - gitleaks находит в изменениях токен, ключ или пароль (правила — стандартные
     плюс `.gitleaks.toml`: токены harness, OAuth rclone, публичные ссылки облаков);
   - добавленные строки или имена файлов совпадают с вашим `local\denylist.txt`.
3. **CI** — gitleaks проверяет всю историю каждого push и pull request, так что
   утечка не пройдёт незамеченной, даже если хук не включён.

## Личный стоп-лист

`local\denylist.txt` — по одному регулярному выражению на строку, `#` —
комментарий. Файл игнорируется Git, поэтому сами стоп-слова тоже не
публикуются. Если в клоне его нет, хук берёт общий для всех клонов список
`%USERPROFILE%\.rdc-workstation-harness\local\denylist.txt`. Там же удобно
держать и сам загрузчик — вне любого клона. Пример:

```text
# облако и аккаунты
my-cloud-provider|share\.my-cloud\.example
my-login@example\.com
# имя ПК и адреса
DESKTOP-ABC123
100\.64\.\d+\.\d+
# рабочие проекты
PROJECT_CODE_\w+
```

## Установка gitleaks

Хук ищет `gitleaks` в PATH или в `%LOCALAPPDATA%\Programs\gitleaks\`. Возьмите
`gitleaks_<версия>_windows_x64.zip` со страницы релизов
<https://github.com/gitleaks/gitleaks/releases>, сверьте SHA-256 с
`checksums.txt` и распакуйте в эту папку. Без gitleaks хук продолжает проверять
`local/` и стоп-лист и предупреждает, что поиск секретов пропущен.

## Если что-то уже попало в Git

Удаление файла новым коммитом не убирает его из истории. Сразу отзовите
раскрытое: перевыпустите токены (`install.ps1 -RotateTokens`), отзовите OAuth
облака, удалите опубликованные файлы. Затем перепишите историю
(`git filter-repo`) и принудительно обновите удалённую ветку.
