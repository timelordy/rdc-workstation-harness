# Revit Bridge

## Поддерживаемые версии

Текущий исходник и build-скрипт рассчитаны на Revit 2022, 2023 и 2024,
работающие на .NET Framework. Revit 2025+ перешёл на .NET 8 и требует отдельной
реализации/сборки; этот репозиторий не заявляет ложную совместимость с ним.

## Сборка и установка

```powershell
.\scripts\install-revit-bridge.ps1 -RevitYear 2022
```

Скрипт:

1. находит `RevitAPI.dll` и `RevitAPIUI.dll` установленной версии;
2. компилирует `src\revit_bridge\RevitBridge.cs` локальным .NET compiler;
3. копирует DLL в runtime harness;
4. создаёт `.addin` manifest текущего пользователя;
5. не добавляет Autodesk binaries в Git.

Для нестандартного пути:

```powershell
.\scripts\install-revit-bridge.ps1 `
  -RevitYear 2022 `
  -RevitInstallDir "D:\Autodesk\Revit 2022"
```
## Как работает

Add-in открывает loopback listener `127.0.0.1:17323`. HTTP thread только
принимает запрос и кладёт его в очередь. Выполнение Revit API происходит на
главном потоке через событие `Idling`; прямой вызов API из фонового потока не
используется.

Доступные действия адаптера:

- `health` — жив ли listener;
- `status` — версия Revit и открытые документы;
- `csharp` — выполнить доверенное тело C#;
- `raw` — передать низкоуровневый запрос bridge.

Runtime C# получает `UIApplication`, активные `UIDocument`/`Document` и словарь
аргументов. Любое изменение модели должно выполняться внутри Revit Transaction.

## Рабочая дисциплина

Перед изменениями:

1. убедитесь, что открыт правильный документ;
2. синхронизируйте/сохраните модель;
3. ограничьте набор элементов и выведите preview/count;
4. используйте понятное имя транзакции;
5. при ошибке выполняйте rollback;
6. после операции проверьте количество и ключевые параметры затронутых элементов.

Bridge может изменить открытую модель с правами пользователя Revit. Не
используйте его как общую службу для недоверенных клиентов.
## Проверка

После установки полностью перезапустите Revit:

```powershell
Invoke-RestMethod http://127.0.0.1:17323/health
.\scripts\diagnose.ps1
```

Если health отсутствует:

- проверьте, что manifest лежит в папке нужного года;
- проверьте абсолютный путь `Assembly` в `.addin`;
- откройте журнал Revit и окно загрузки add-ins;
- убедитесь, что DLL собрана против API той же основной версии;
- проверьте, что порт 17323 не занят другим процессом.

## Токен и порт

Revit token создаётся при первом запуске add-in в
`%USERPROFILE%\.chatgpt-desktop-agent\revit.token`. Для его смены закройте Revit,
удалите только этот файл и снова запустите Revit.

Для нестандартного порта задайте пользовательскую переменную
`REVIT_BRIDGE_PORT` до запуска Revit и тот же порт в конфигурации Desktop Agent.
Обычная установка использует 17323 и не требует этой настройки.

## Удаление

`uninstall.ps1` удаляет manifest `RdcHarness.RevitBridge.addin` и runtime DLL.
Токен сохраняется, пока не указан общий `-RemoveTokens` или он не удалён вручную.
