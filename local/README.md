# local/

Папка для личных файлов этой машины. Git видит только этот README; всё остальное
в `local/` игнорируется.

Сюда кладут то, что нельзя публиковать:

- загрузчик для `RDC_HARNESS_SHARE_CMD` (ваше облако, ваш сервер);
- список личных стоп-слов для pre-commit хука — `local/denylist.txt`;
- любые заметки с адресами, именами аккаунтов, путями к проектам.

Подробности: [docs/LOCAL_PRIVATE_RU.md](../docs/LOCAL_PRIVATE_RU.md).
